# Комплексные задачи по Python

**Итоговая практика после 4 недель**  
Три варианта занятия на **1 час 20 минут** с последовательными уровнями сложности.

> Каждая задача начинается с минимально работающей версии и постепенно обрастает новыми правилами. Студенты могут остановиться на достигнутом уровне; последние уровни рассчитаны на тех, кто идёт быстрее группы.

В документе:

1. Модератор чата
2. Кодовый сейф
3. Регистрация в сервисе

**Базовые уровни:** переменные, ввод, условия, строки, циклы, `break` / `continue`.  
**Продвинутые уровни:** списки, словари, собственные функции.

---

# 1. Модератор чата

Программа принимает сообщения пользователя, проверяет их по правилам и постепенно превращается в мини-систему модерации.

| Формат | Основные навыки | Время |
|---|---|---:|
| 6 уровней | строки, `in`, методы строк, `if/elif/else`, `for`, `while`, накопители, `break` | 80 минут |

## Уровень 1. Подготовка одного сообщения — 10 мин

**Фокус:** `input`, `strip`, `lower`, `len`, f-строки.

- Считать сообщение пользователя.
- Убрать пробелы по краям.
- Привести сообщение к нижнему регистру.
- Вывести обработанный текст и количество символов.

```text
Сообщение:    Привет Мир   
Текст: привет мир
Символов: 10
```

## Уровень 2. Первое правило модерации — 10 мин

**Фокус:** оператор `in`, `if / else`.

- Задать одно запрещённое слово, например «спам».
- Если запрещённое слово встречается внутри сообщения — вывести «Сообщение заблокировано».
- Иначе вывести «Сообщение опубликовано».
- Проверка должна работать независимо от регистра введённого текста.

```text
Сообщение: Купить СПАМ прямо сейчас
Сообщение заблокировано
```

## Уровень 3. Несколько правил — 15 мин

**Фокус:** цикл по строке, накопители, логические условия.

- Заблокировать пустое сообщение.
- Заблокировать сообщение длиннее 100 символов.
- Заблокировать сообщение с запрещённым словом.
- Посчитать количество символов `!` циклом. Если их больше 5 — заблокировать.
- Для каждого отклонённого сообщения вывести понятную причину.

**Усложнение:** не использовать готовый `.count()` для подсчёта восклицательных знаков.

## Уровень 4. Полноценный чат — 15 мин

**Фокус:** `while`, `break`, несколько накопителей.

- Принимать сообщения одно за другим.
- После каждого сообщения сразу печатать результат проверки.
- Слово «выход» завершает программу и не считается сообщением.
- Посчитать общее число сообщений, число опубликованных и число заблокированных.

```text
Введите сообщение: привет
Опубликовано

Введите сообщение: купи спам
Заблокировано

Введите сообщение: выход

Всего сообщений: 2
Опубликовано: 1
Заблокировано: 1
```

## Уровень 5. Список запрещённых слов — 15 мин

**Фокус:** списки, цикл по списку, `break`.

- Создать список запрещённых слов.
- Сообщение блокируется, если найдено хотя бы одно слово из списка.
- После нахождения первого совпадения дальнейшую проверку списка прекратить.
- Вывести, какое именно слово стало причиной блокировки.

```python
bad_words = ["спам", "реклама", "казино"]
```

## Уровень 6. Статистика модерации — 15 мин

**Фокус:** словари, функции.

- Хранить статистику в словаре: всего, опубликовано, заблокировано.
- Отдельно считать причины блокировки.
- Вынести проверку одного сообщения в функцию.
- В конце вывести сводку по причинам блокировки.

```python
stats = {
    "all": 7,
    "published": 5,
    "blocked": 2
}

reasons = {
    "bad_word": 1,
    "too_long": 0,
    "too_many_exclamations": 1
}
```

> **Критерий завершения:** программа не падает на пустом вводе, корректно обрабатывает регистр и пробелы, завершает чат по команде «выход» и выводит итоговую статистику.

# 2. Кодовый сейф

Игрок пытается подобрать секретный четырёхзначный код. На каждом уровне программа становится ближе к игре Mastermind.

| Формат | Основные навыки | Время |
|---|---|---:|
| 6 уровней | строки и индексы, условия, `while/for`, `break`, счётчики, списки | 80 минут |

## Уровень 1. Одна попытка — 10 мин

**Фокус:** `input`, сравнение строк, `if / else`.

- В программе заранее задан секретный код.
- Пользователь вводит одну попытку.
- Если код совпал — вывести «Сейф открыт». Иначе — «Неверный код».

```text
secret = "5831"

Код: 5831
Сейф открыт
```

## Уровень 2. Проверка формата — 10 мин

**Фокус:** `len`, цикл по строке или `isdigit`, `continue`.

- Код должен состоять ровно из 4 символов.
- Все символы должны быть цифрами.
- Некорректный ввод не должен сравниваться с секретным кодом.
- Вывести отдельное сообщение «Ошибка формата».

```text
Код: 12a4
Ошибка формата

Код: 12345
Ошибка формата
```

## Уровень 3. Пять попыток — 15 мин

**Фокус:** `while` или `for`, счётчик попыток, `break`.

- У игрока есть 5 корректных попыток.
- После ошибки показать, сколько попыток осталось.
- При правильном коде немедленно завершить цикл.
- Если попытки закончились — вывести сообщение о блокировке сейфа.
- Ошибки формата попытку не расходуют.

```text
Код: 1234
Неверный код. Осталось попыток: 4

Код: 5831
Сейф открыт
```

## Уровень 4. Подсказки по позициям — 20 мин

**Фокус:** индексация, цикл, накопитель.

- После неправильной попытки сравнить секретный код и введённый код посимвольно.
- Посчитать, сколько цифр стоят на правильных позициях.
- Вывести количество совпавших позиций.
- Программа должна работать для любого четырёхзначного секретного кода.

```text
Секрет: 5831
Ввод:   5137
Совпало позиций: 2
```

## Уровень 5. История попыток — 15 мин

**Фокус:** список, `in`, `continue`.

- Сохранять все корректные попытки в списке.
- Один и тот же код нельзя вводить дважды.
- Повторная попытка не должна уменьшать число оставшихся попыток.
- Перед завершением игры вывести всю историю корректных уникальных попыток.

## Уровень 6. Mastermind — 10 мин

**Фокус:** словари/функции или продвинутая работа со списками.

- Вывести отдельно число цифр на правильных местах.
- Отдельно посчитать правильные цифры, находящиеся на неправильных местах.
- Не считать одну и ту же цифру несколько раз.
- Вынести анализ попытки в функцию `check_code(secret, attempt)`.

```text
На правильных местах: 2
Правильные цифры на других местах: 1
```

> **Критерий завершения:** некорректный ввод не расходует попытки, повторные коды отсекаются, правильный код сразу завершает игру, а подсказки считаются корректно.

# 3. Регистрация в сервисе

Студенты создают систему регистрации и входа: сначала проверяют один логин и пароль, затем переходят к нескольким пользователям.

| Формат | Основные навыки | Время |
|---|---|---:|
| 6 уровней | методы строк, условия, циклы по строке, флаги, `while`, списки, словари, функции | 80 минут |

## Уровень 1. Создание аккаунта — 10 мин

**Фокус:** `input`, переменные, f-строки.

- Считать имя пользователя и пароль.
- После ввода вывести сообщение о создании аккаунта.
- Пароль в итоговом сообщении не выводить.

```text
Логин: ksenia
Пароль: qwerty
Аккаунт ksenia создан
```

## Уровень 2. Правила логина — 10 мин

**Фокус:** `strip`, `lower`, `len`, `in`, `if/elif/else`.

- Убрать пробелы по краям и привести логин к нижнему регистру.
- Логин не может быть пустым.
- Длина логина: от 4 до 15 символов.
- Внутри логина не должно быть пробелов.
- Если правило нарушено — вывести конкретную причину.

## Уровень 3. Сильный пароль — 15 мин

**Фокус:** `for` по строке, флаги, логические операторы.

- Пароль должен содержать минимум 8 символов.
- В пароле должна быть хотя бы одна цифра.
- Должна быть хотя бы одна заглавная и хотя бы одна строчная буква.
- Проверить символы циклом и использовать флаги `has_digit`, `has_upper`, `has_lower`.
- Вывести все найденные проблемы, а не только первую.

```text
Введите пароль: qwerty
Слабый пароль:
- меньше 8 символов
- нет цифры
- нет заглавной буквы
```

## Уровень 4. Повторять до корректного пароля — 15 мин

**Фокус:** `while`, повторный ввод, `continue`.

- Если пароль не прошёл проверку — запросить его снова.
- Повторять до тех пор, пока пользователь не введёт корректный пароль.
- После успешной проверки создать аккаунт и выйти из цикла.

```text
Введите пароль: qwerty
Слабый пароль

Введите пароль: Qwerty
Нет цифры

Введите пароль: Qwerty7x
Аккаунт создан
```

## Уровень 5. Несколько пользователей — 15 мин

**Фокус:** списки, проверка уникальности.

- Хранить зарегистрированные логины в списке.
- Нельзя зарегистрировать уже существующий логин.
- После успешной регистрации добавить новый логин в список.
- Разрешить регистрировать пользователей до команды «выход».

## Уровень 6. Хранилище пользователей и вход — 15 мин

**Фокус:** словарь, функции, ограничение попыток.

- Перейти от списка логинов к словарю `users`, где ключ — логин, значение — пароль.
- После регистрации добавить режим авторизации.
- На вход дать не более 3 попыток.
- Вынести проверку пароля и авторизацию в отдельные функции.

```python
users = {
    "anna": "Qwerty1x",
    "ivan": "Python123"
}

check_password(password)
register(users)
login(users)
```

> **Критерий завершения:** логин нормализуется до проверки, программа объясняет ошибки пароля, повторяет ввод до корректного значения и не позволяет создавать дублирующиеся аккаунты.

---

## Как использовать на занятии

- Выдать всем только уровни 1–4 как обязательную часть.
- Уровень 5 открыть тем, кто закончил базовую часть раньше.
- Уровень 6 использовать как бонус: здесь естественно появляются словари и функции.
- Не выдавать готовую архитектуру программы: каждый новый уровень должен требовать доработки уже написанного решения, а не написания отдельного файла с нуля.
