# A. Совместная поездка

Компания друзей едет за город на одной машине. Один человек оплатил весь бензин, а остальные должны вернуть ему свою часть расходов.

Программа получает имя того, кто заплатил, общую стоимость бензина и количество людей в машине, включая платившего.

Нужно вывести, сколько приходится на одного человека и сколько денег должны вернуть тому, кто оплатил бензин.

Обе денежные величины округлите до двух знаков после запятой функцией `round` и выводите ровно так, как их печатает Python.

## Формат ввода

Три строки:

1. имя оплатившего — одно слово без пробелов;
2. стоимость бензина — число, может быть дробным;
3. количество людей в машине — целое число.

Ограничения:

`0 ≤ стоимость ≤ 1 000 000`

`1 ≤ количество людей ≤ 100`

## Формат вывода

Две строки:

```text
На одного человека: <сумма> руб.
<имя> получит обратно: <сумма> руб.
```

## Пример 1

**Ввод**
```text
Ира
2400
4
```

**Вывод**
```text
На одного человека: 600.0 руб.
Ира получит обратно: 1800.0 руб.
```

## Пример 2

**Ввод**
```text
Макс
999.99
3
```

**Вывод**
```text
На одного человека: 333.33 руб.
Макс получит обратно: 666.66 руб.
```

# B. Код студента

Университет формирует короткий код студента по имени и фамилии.

Программа получает строку вида `<Имя Фамилия>`. В начале и в конце строки могут быть лишние пробелы, между словами — один или несколько пробелов. Регистр букв произвольный.

Код строится так:

- первые две буквы имени;
- символ `-`;
- последние три буквы фамилии;
- всё строчными буквами.

Гарантируется, что имя содержит не меньше двух букв, а фамилия — не меньше трёх.

## Формат ввода

Одна строка вида:

```text
<Имя Фамилия>
```

Длина строки не превышает 100 символов.

## Формат вывода

Одна строка — код студента строчными буквами.

## Пример 1

**Ввод**
```text
Иван Петров
```

**Вывод**
```text
ив-ров
```

## Пример 2

**Ввод**
```text
   АННА     СИДОРОВА
```

**Вывод**
```text
ан-ова
```

# C. Выручка за n дней

Небольшой магазин записывает финансовый результат каждого дня.

Положительное число означает прибыль, отрицательное — убыток, ноль — день без прибыли и убытка.

Нужно определить:

- сколько дней были прибыльными;
- общую сумму результатов за все дни;
- в какой день результат был максимальным.

Если максимальный результат встречается несколько раз, нужно вывести **последний** такой день.

## Формат ввода

В первой строке целое число `n` — количество дней.

Далее `n` строк, в каждой записано одно целое число — результат соответствующего дня.

Ограничения:

`0 ≤ n ≤ 1000`

`-100000 ≤ результат ≤ 100000`

## Формат вывода

Если `n = 0`, вывести:

```text
Нет данных
```

Иначе вывести три строки:

```text
Прибыльных дней: <количество>
Итог: <сумма>
Лучший день: <номер дня>, результат <значение>
```

Дни нумеруются с 1 в порядке ввода.

## Пример 1

**Ввод**
```text
5
300
-200
0
700
700
```

**Вывод**
```text
Прибыльных дней: 3
Итог: 1500
Лучший день: 5, результат 700
```

# D. Парковка

Платная парковка принимает оплаты по одной операции в строке. Сколько операций будет — заранее неизвестно.

Работа парковки заканчивается в одном из двух случаев:

- оператор вводит служебную строку `close`;
- суммарная выручка достигает или превышает 5000 рублей.

Если цель достигнута, парковка закрывается сразу после этой оплаты, и до следующих строк программа уже не доходит.

Иногда терминал присылает значение `0`. Такая строка не считается оплатой и не увеличивает ни число операций, ни сумму.

Отрицательное значение считается ошибочным и тоже полностью игнорируется.

## Формат ввода

Строки, каждая из которых содержит либо целое число — сумму оплаты, либо слово:

```text
close
```

Если выручка не достигнет 5000 рублей, ввод гарантированно завершится строкой `close`.

Ограничения:

`-100000 ≤ сумма ≤ 100000`

не более 1000 строк ввода.

## Формат вывода

Три строки:

```text
Оплат: <количество>
Выручка: <сумма>
<статус>
```

Статус:

```text
План выполнен
```

если парковка закрылась автоматически после достижения 5000 рублей, иначе:

```text
Парковка закрыта
```

## Пример 1

**Ввод**
```text
1200
0
-300
1800
700
close
```

**Вывод**
```text
Оплат: 3
Выручка: 3700
Парковка закрыта
```

## Пример 2

**Ввод**
```text
2000
1500
1700
999
```

**Вывод**
```text
Оплат: 3
Выручка: 5200
План выполнен
```

# E. Анализ заголовков

Редактор получает несколько строк с заголовками статей и хочет собрать простую статистику по словам.

Слово — последовательность букв. Внутри строки слова разделены одним или несколькими пробелами. Пустые строки возможны.

Нужно определить:

- сколько слов встретилось всего;
- сколько слов имеют длину не меньше 7 букв;
- какое слово было самым длинным;
- сколько букв `а` встретилось во всех словах вместе, без учёта регистра.

Если несколько слов имеют одинаковую максимальную длину, вывести **первое** из них по порядку.

## Формат ввода

В первой строке целое число `n` — количество строк текста.

Далее `n` строк.

Ограничения:

`0 ≤ n ≤ 100`

длина каждой строки не превышает 200 символов;

строки состоят только из русских букв и пробелов.

## Формат вывода

Если во всём тексте нет ни одного слова, вывести:

```text
Текст пуст
```

Иначе вывести четыре строки:

```text
Слов всего: <количество>
Длинных слов: <количество>
Самое длинное слово: <слово>
Букв а всего: <количество>
```

## Пример 1

**Ввод**
```text
3
Новая статья
анализ данных

Алгоритмы
```

**Вывод**
```text
Слов всего: 5
Длинных слов: 2
Самое длинное слово: Алгоритмы
Букв а всего: 6
```

# F. Вход в личный кабинет

Система хранит правильный пароль. Пользователю разрешено не более `k` ошибочных попыток.

Перед проверкой из введённой строки нужно убрать пробелы по краям. Регистр символов имеет значение.

Если после удаления пробелов строка оказалась пустой, такая строка не считается попыткой.

Если пароль введён верно, проверка завершается сразу.

## Формат ввода

В первой строке записан правильный пароль.

Во второй строке целое число `k` — максимальное количество непустых попыток.

Далее вводятся строки с вариантами пароля.

Ввод гарантированно содержит достаточно строк, чтобы либо пароль был введён верно, либо попытки закончились.

Ограничения:

`1 ≤ k ≤ 20`

длина пароля и каждой попытки не превышает 100 символов.

## Формат вывода

Если пароль введён верно:

```text
Доступ разрешён
Попыток использовано: <количество>
```

Если попытки закончились:

```text
Доступ заблокирован
Попыток использовано: <количество>
```

## Пример 1

**Ввод**
```text
Python2026
3
   
python2026
 Python2026 
```

**Вывод**
```text
Доступ разрешён
Попыток использовано: 2
```

# G. Серия тренировок

Спортсмен каждый день записывает количество пройденных шагов.

День считается успешным, если было пройдено не меньше 10 000 шагов.

Нужно определить:

- общее количество успешных дней;
- длину самой длинной серии успешных дней подряд;
- номер дня, в который закончилась эта серия.

Если несколько серий имеют одинаковую максимальную длину, выбрать ту, которая закончилась **позже**.

## Формат ввода

В первой строке целое число `n` — количество дней.

Далее `n` строк, в каждой одно целое число — количество шагов.

Ограничения:

`0 ≤ n ≤ 1000`

`0 ≤ шаги ≤ 100000`

## Формат вывода

Если `n = 0`, вывести:

```text
Нет данных
```

Иначе вывести три строки:

```text
Успешных дней: <количество>
Максимальная серия: <длина>
Серия закончилась в день: <номер>
```

Если успешных дней не было, номер дня должен быть `0`.

## Пример 1

**Ввод**
```text
7
12000
15000
3000
10000
11000
13000
5000
```

**Вывод**
```text
Успешных дней: 5
Максимальная серия: 3
Серия закончилась в день: 6
```

# H. Очередь в кофейне

Бариста обслуживает клиентов одного за другим. В каждой строке записана стоимость заказа.

Значение `0` означает, что клиент передумал и ушёл — такой случай не считается заказом.

Отрицательное число означает ошибку кассы и должно быть пропущено.

Обслуживание заканчивается словом `end`.

Нужно определить количество принятых заказов, общую выручку и стоимость самого дорогого заказа.

Если ни одного заказа принято не было, вместо максимальной стоимости нужно вывести `0`.

## Формат ввода

Строки, каждая из которых содержит либо целое число, либо слово:

```text
end
```

Ограничения:

`-100000 ≤ стоимость ≤ 100000`

не более 1000 строк ввода.

## Формат вывода

Три строки:

```text
Заказов: <количество>
Выручка: <сумма>
Самый дорогой заказ: <стоимость>
```

## Пример 1

**Ввод**
```text
350
0
-20
900
500
end
```

**Вывод**
```text
Заказов: 3
Выручка: 1750
Самый дорогой заказ: 900
```

# I. Проверка кода заказа

Интернет-магазин использует коды заказов специального формата.

Корректный код содержит ровно 8 символов:

- первые два символа — заглавные латинские буквы;
- третий символ — дефис `-`;
- следующие четыре символа — цифры;
- последний символ — одна из букв `A`, `B` или `C`.

Перед проверкой нужно убрать пробелы по краям строки.

Нужно определить, является ли введённая строка корректным кодом заказа.

## Формат ввода

Одна строка — код заказа.

Длина исходной строки не превышает 100 символов.

## Формат вывода

Если код корректный:

```text
Код принят
```

Иначе:

```text
Неверный код
```

## Пример 1

**Ввод**
```text
AB-2048C
```

**Вывод**
```text
Код принят
```

## Пример 2

**Ввод**
```text
ab-2048C
```

**Вывод**
```text
Неверный код
```

# J. Посещаемость групп

На учебной неделе преподаватель отмечает посещаемость нескольких студентов.

Для каждого студента вводятся данные за несколько занятий: `1` означает, что студент присутствовал, `0` — отсутствовал.

Нужно определить:

- сколько посещений было всего;
- номер студента с наибольшим количеством посещений;
- сколько студентов посетили все занятия.

Если несколько студентов имеют одинаковое максимальное количество посещений, вывести **последнего** из них.

## Формат ввода

В первой строке целое число `n` — количество студентов.

Во второй строке целое число `m` — количество занятий.

Далее вводятся `n × m` строк.

Сначала идут `m` значений для студента 1, затем `m` значений для студента 2 и так далее.

Каждая строка содержит `0` или `1`.

Ограничения:

`1 ≤ n ≤ 100`

`1 ≤ m ≤ 100`

## Формат вывода

Три строки:

```text
Посещений всего: <количество>
Лучший студент: <номер>
Без пропусков: <количество студентов>
```

## Пример 1

**Ввод**
```text
3
4
1
1
0
1
1
1
1
1
0
1
1
1
```

**Вывод**
```text
Посещений всего: 10
Лучший студент: 2
Без пропусков: 1
```
